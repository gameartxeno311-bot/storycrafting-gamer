# Contributing

This is a creative persona project. Contributions should strengthen the character's identity and creative output.

## Good contributions

- Original game concepts
- Story prompts
- World-building ideas
- Animation concepts
- Social-media drafts
- Improvements to documentation

## Guidelines

1. Keep ideas original.
2. Maintain the persona's friendly, curious, creator-focused voice.
3. Clearly label fictional concepts as concepts.
4. Avoid presenting the AI persona as a real human.
5. Keep the project welcoming and collaborative.
